# 📊 Excel Sales Analysis & Dashboard

## 📌 Project Overview

This project is an **E-Commerce Sales Analysis Dashboard created using Microsoft Excel**.

The project focuses on transforming raw sales data into a clean and structured dataset, performing data analysis using Excel, and creating an interactive dashboard to understand sales performance, customer behavior, order status, sales channels, and geographical performance.

The main objective was to use Excel as a complete **Data Analyst tool for data cleaning, analysis, visualization, and business reporting**.

---

## 🎯 Project Objectives

* Clean and prepare raw sales data for analysis
* Analyze overall sales and order performance
* Compare sales between male and female customers
* Analyze order status and fulfillment performance
* Identify top-performing states
* Analyze customers based on age and gender
* Understand sales/order distribution across different channels
* Create an interactive annual sales dashboard
* Generate meaningful business insights from the data

## 📈 Analysis Performed

### 1. Sales vs Orders

Analyzed monthly sales amount and order volume to understand sales performance throughout the year.

### 2. Men vs Women

Compared sales contribution between male and female customers.

### 3. Order Status

Analyzed the distribution of:

* Delivered
* Cancelled
* Returned
* Refunded

This helps understand the overall order fulfillment and post-order performance.

### 4. State-wise Sales

Analyzed sales across different states to identify the locations contributing the most to overall sales.

### 5. Age & Gender Analysis

Analyzed customer/order distribution across different age groups and genders, including:

* Teenagers
* Adults
* Seniors

### 6. Sales Channel Analysis

Compared order contribution across different e-commerce channels such as:

* Amazon
* Myntra
* Flipkart
* Ajio
* Meesho
* Nalli
* Others
